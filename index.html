About ReadmeForge

ReadmeForge is a free README.md generator for GitHub. It builds the file from ready-made sections, so you do not have to remember Markdown syntax, shields.io badge URLs or HTML alignment. Add the sections you want, fill in the fields, and the finished Markdown is generated with a live preview that matches how GitHub renders it.

What you can do

Add sections

Title, badges, features, installation, usage, FAQ, roadmap, screenshots and more. Reorder or remove them at any time.

Build badges

Generate shields.io badges for stars, forks, licence, last commit, npm and PyPI versions, or a custom label.

Preview as you type

The preview uses GitHub-flavoured Markdown, including tables, task lists and aligned images.

Profile READMEs

Add GitHub stats, a streak counter, top languages, trophies and social links for your profile page.

Start from a template

Choose from Starter, Minimal, Library, API, Profile or Awesome list layouts.

Nothing is uploaded

The editor runs entirely in your browser and keeps your draft in local storage.

How to use it

  1. Pick a template or start with an empty README in the Builder tab.
  2. Add sections from the list on the left.
  3. Fill in the fields and check the preview.
  4. Copy the Markdown or download it as README.md, then add it to your repository.

Frequently asked questions

Is ReadmeForge free?

Yes. It is free and open source. There is no sign-up and no server; everything runs in your browser.

Is my content uploaded anywhere?

No. The editor is fully client-side and your draft is stored only in your browser's local storage.

Can I create a GitHub profile README?

Yes. The Profile template adds a header, GitHub stats cards, a streak counter and social links.

How do I add the README to my repository?

Download README.md, then upload it to the root of your repository and commit. For a profile README, create a repository named after your username and add the file there.

Which Markdown features are supported?

GitHub-flavoured Markdown: headings, lists, task lists, tables, blockquotes, fenced code blocks, links, images, inline HTML for centred headers, and collapsible sections.
